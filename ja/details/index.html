01音に反応

4096 点 FFT、64 バンドの対数分割。

ハン窓、実数 FFT、対数分割、ピーク減衰の平滑化を経て、壁紙ページが期待する 128 個の値にまとめます。 設定で入力デバイスを選べ、そのすぐ横にリアルタイムのスペクトラムバーがあるので、信号が来ているかどうかが 一目で分かります。 既定はオフなので、有効にしない限りマイクの許可を求めることはありません。

20 Hz200 Hz2 kHz20 kHz
正直に言うと：macOS はアプリがシステムの再生音を直接キャプチャすることを許していません。 BlackHole のようなループバックデバイスを入れないかぎり、拾えるのはマイク越しの周囲の音であって、 いま聴いている曲ではありません。機能自体は完成していますが、この前提だけはご自身で満たす必要があります —— これはプラットフォームの制限であって、作りかけという意味ではありません。
02はじめ方

あなたがどこから来たかで、Swaylume の入口も変わります。

はじめてライブ壁紙を設定するのと、Windows のコレクションを持ち込むのと、自分の作品を投稿するのとでは、 必要なものが違います。だからここでは 3 つの道を分けています。全員をひとつの README に放り込みません。

01 / すぐ使いたい

ライブ壁紙を 1 枚選んで、デスクトップに置く。

カタログから `.swaylume` をダウンロードして、アプリにドラッグするだけ。動画・画像・ウェブ・レイヤー壁紙は、それぞれ専用のネイティブレンダラーで動きます。

02 / Wallpaper Engine から

コレクションを持ち込む。ゼロからやり直さない。

変換ツールが読むのは、すでにお使いのコンピュータにある Wallpaper Engine のプロジェクトだけです。Steam へのログインもダウンロードもありません。動画とウェブ形式を優先して対応し、Scene には事前レンダリングの手順を明示しています。

03 / 壁紙をつくる人へ

1 枚つくって、誰かのデスクトップを動かす。

まずは費用ゼロのカタログへの投稿から。明確なフォーマット、チェックサム、バージョン履歴、そして目に見える審査の記録があります。アップロードを本格的に開放するまで、リスクを作者に押しつけることはしません。

04境界線

あなたのデスクトップは、誰かのクラウド素材庫ではありません。

ライブ壁紙は多くのローカルファイルに触れられます。だから Swaylume の既定方針は、権限は少なく、データは残さず、 大きなことは言わない。できることはきちんとやり、できないことははっきり伝えます。

ローカル優先。

壁紙、ブックマーク、インポート履歴、診断レポートはすべてあなたの Mac の中にあります。自動アップロードはなく、広告トラッキングのスクリプトもありません。

公開 API のみ。

デスクトップのウインドウレベル、複数 Space、省電力方針、ファイルアクセスはすべて macOS の公開機能を使っています。App Store 審査への道を塞ぎません。

診断は持ち出せます。

黒画面や互換性の問題に当たったら、秘匿化済みのローカルレポートを書き出せます。含まれるのは状態とエラーで、壁紙ファイルは含まれません。

できないふりはしません。

Windows のアプリケーション型壁紙と Scene のネイティブ描画には対応を約束しません。Scene には動画への事前レンダリングという正攻法があります。

05よくある質問

ダウンロードの前に、たぶん知りたいこと。

電力を食いませんか？
デフォルトでは、誰にも見えないときは 1 フレームも描画しません。画面がウインドウで完全に覆われた場合、ロック画面、ディスプレイスリープ、システムスリープ、低電力モードにはそれぞれ停止理由があり、復帰時に自動再開します。任意の「ロック解除遅延ゼロ（プリウォーム）」もアニメーションとメディアを停止し、少量の追加メモリと引き換えにビデオパイプラインと Web プロセスだけを待機させます。システムスリープ中はプリウォームせず、有効化前に app が影響を説明します。判断はすべて 1 つのガバナーに集約され、停止理由はログに残ります。
自分の動画や画像を使えますか？
使えます。ウインドウにドラッグするだけです。動画は mp4 / mov / m4v（H.264 または HEVC）、画像は一般的な形式と GIF、ウェブ壁紙は HTML / WebGL に対応します。webm / VP9 はそのままでは再生できず、先に変換が必要です —— AVFoundation がこの 2 つのコーデックをデコードできないためで、プラットフォームの制限です。
Wallpaper Engine と比べてどうですか？
正直に言うと、それぞれに強みがあります。あちらにあってこちらにないもの：数百万点のワークショップ、ネイティブの Scene 描画、成熟したエディタ。こちらにあってあちらにないもの：Space ごとに別の壁紙（Windows では実現できません）、日の出・日の入りでの自動切り替え、そして明らかに真面目な省電力設計。さらに向こうには macOS 版がなく、手持ちのコレクションは変換ツールで持ってこられます。
初回起動がブロックされました。壊れているのですか？
いいえ。このビルドはまだ Apple の公証を受けていません —— 公証には有料の開発者アカウントが必要です。macOS は「開発元を検証できません」と表示しますが、「システム設定 →プライバシーとセキュリティ →セキュリティ」で一度「このまま開く」を押せば済みます。すべてマウス操作、ターミナル不要、初回だけです。詳しい手順はダウンロード欄にあります。
データはアップロードされますか？
されません。壁紙、ブックマーク、インポート履歴、診断レポートはすべてあなたの Mac に留まります。自動アップロードはなく、広告トラッキングのスクリプトもありません。通信するのは、あなたが自分で壁紙カタログを更新したときにインデックスを取得する場面だけです。診断レポートは自分で書き出したときだけ生成され、含まれるのは状態とエラーで、壁紙ファイルは含まれません。
対応している Mac は？
macOS 14 以降。Apple シリコンでも Intel でも動作します（ユニバーサルバイナリ）。マルチディスプレイと AirPlay のサブディスプレイはどちらも実機で検証済みです。
