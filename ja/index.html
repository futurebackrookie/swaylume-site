Swaylume

デスクトップが、生きている。

ビデオ、WebGL、2.5D の壁紙が、デスクトップアイコンのすぐ下で動きます。Mac のためにゼロから作りました。

無料でダウンロード

スクロール

録画した映像でも、ウェブの演出でもありません。あなたのデスクトップが、呼吸しています。

注目の壁紙

一枚選ぶだけ。あとはデスクトップにおまかせ。

ディスプレイの中で動いているのは、アプリに付属する壁紙そのものです。宣伝用のアニメーションではありません。選んで、切り替わる様子を見てください。

インストールしてすぐ 26 枚の壁紙が使えます。手持ちのビデオ、画像、ウェブページも使えます。

アイコンの下に。ウインドウの後ろに。

壁紙はデスクトップピクチャとデスクトップアイコンのあいだの層にいます。ウインドウはいつもどおり、アイコンもいつもどおりクリックできます。何も譲る必要はありません。

3 種類の壁紙、それぞれの道で。

ビデオはハードウェアデコーダへ、ウェブは WebKit へ、レイヤー画像は Core Animation へ。どれも間に合わせではありません。

WebGL を、思いどおりに。

壁紙が宣言したスライダがインスペクタに現れます。動かしてみてください —— 変わるのは上の壁紙そのもので、アプリと同じインターフェイスを通っています。

つなぎ目

ビデオは、つなぎ目なくループ。

つなぎ目で黒いフレームも引っかかりもありません。4K60 は GPU にまかせるので、CPU はほとんど働きません。

デスクトップペット

一枚の写真から、デスクトップペットが生まれる。

飼い猫の写真を何枚か渡すと、Swaylume が毛色、体つき、しっぽを測って、そっくりなピクセルの猫を作ります。デスクトップに住んでいて、フォーカスを奪いません。

ポインタを入れて、クリックしてみてください

あなたの猫そっくりに

毛色、頭と体の比率、脚の長さまで写真から測ります。テンプレートの使い回しではありません。

自分から会いに来る

ひまなときは散歩したり、毛づくろいしたり、うたた寝したり。気になるとポインタのほうへ歩いてきます。

なでると反応する

頭をなでると目を細めてのどを鳴らし、クリックすると鳴きます。⌥⌘C でポインタのところへ呼べます。

ディスプレイごとに、それぞれの壁紙を。

ディスプレイごとに壁紙を選ぶことも、全部同じにすることも、一枚の絵をすべての画面にまたがらせることもできます。Space ごとに変えることもできます。

3440 × 1440
1920 × 1080

ビデオと画像はそのまま横断できます。ウェブ壁紙は横断への対応を宣言している必要があり、そうでなければ各画面に一つずつ描かれます。

見えていないときは、1 フレームも描かない。

  1. 見ているあいだだけ、動くディスプレイのリフレッシュレート、または設定した上限に合わせます。
  2. ウインドウで覆われたら、すぐに一時停止いちばん効果の大きい省電力機能で、最初からオンです。
  3. 低電力モードでは、30 に下げるシステムの設定に従います。バッテリー駆動中は一時停止を選ぶこともできます。
  4. ロック中もスリープ中も、完全に止まるMac がスリープしているあいだ、バックグラウンドには何も残しません。

設定を開く必要はありません。

どのアプリが前面にあっても使える、4 つのグローバルショートカット。このページで ⌥ と ⌘ を押してみてください。

⌥⌘P一時停止 / 再開
⌥⌘→次の壁紙
⌥⌘M消音
⌥⌘Cペットを呼ぶ

システムのショートカット登録を使うので、「アクセシビリティ」の許可は不要です —— 壁紙アプリが、あなたの入力をすべて読めるべきではありません。

Wallpaper Engine から移ってきましたか？

コマンドラインツールが、お手元のビデオ壁紙とウェブ壁紙を Swaylume 用のパッケージに変換します。ネット接続も Steam も不要です。

初回起動がブロックされましたか？ それは想定どおりです
  1. Swaylume をダブルクリックして、一度拒否させてください。この手順は飛ばせません —— システムがブロックを記録して初めて、次のボタンが現れます。
  2. 「システム設定」→「プライバシーとセキュリティ」を開きます。
  3. 下へスクロールして「セキュリティ」の項目で、「Swaylume はブロックされました」という行を探します。
  4. その右にある「このまま開く」をクリックし、もう一度確認します。

以降は普通にダブルクリックで開けて、もう確認されません。Swaylume はまだ Apple の公証を受けていません（公証には有料の開発者アカウントが必要です）。アプリに問題があるという意味ではありません。
