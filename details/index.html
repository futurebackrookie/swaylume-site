    01音频响应

    4096 点 FFT，64 段对数分频。

    采样加 Hann 窗、实数 FFT、对数分频、峰值衰减平滑，拼成 128 个值推给壁纸页面。 设置里能选输入设备，旁边就是实时频谱条 —— 让你一眼看出到底有没有信号进来。 默认关闭，不开就不会弹麦克风权限。

    20 Hz200 Hz2 kHz20 kHz
    说实话：壁纸的音频响应拿不到系统播放的声音。 它从输入设备采样 —— 不装 BlackHole 这类环回声卡，采到的就是麦克风里的 环境声，不是你正在放的歌。这是这条链路的前提，得你自己满足。 桌宠的「听到音乐时跟着摇摆」走的是另一条路：macOS 14.2 起的进程音频 tap， 只捕获音乐、视频和浏览器进程的输出，不需要虚拟声卡。两者互相独立， 都只在本机实时分析，不录制、不保存、不上传。
    02怎么开始

    你从哪来，Swaylume 就从哪开始。

    第一次换动态壁纸、把 Windows 的收藏带过来，还是自己做作品投稿，入口不该一样。 所以官网把三条路分开，而不是把所有人扔进一个 README。

    01 / 想马上用

    挑一张动态壁纸，放进桌面。

    从精选目录下载 `.swaylume`，拖进 App。视频、图片、网页和分层壁纸各走自己的原生渲染器。

    浏览精选壁纸
    02 / 来自 Wallpaper Engine

    带上已有收藏，不必从零开始。

    转换器只读取你电脑上已有的 Wallpaper Engine 项目，不登录 Steam、不下载内容。视频和网页类优先支持，Scene 明确给出预渲染路径。

    03壁纸从哪来

    Swaylume 不捆绑内容库，素材你自己挑。

    任何 mp4、图片、HTML 都能直接拖进来用。下面是几个常去的地方 —— 我们不托管、不转售、也不审核这些站点上的内容，只是把路指出来。

    授权明确

    条款逐条核实过：商用免费、无需署名、可修改。App 里的来源列表只收这一类。

    Pexels 视频 ↗ 画质普遍较高，可按方向和分辨率筛选。 Pexels License：免费使用、无需署名、可修改；禁止在其它素材站或壁纸站再分发，禁止出售未修改的副本。

    第三方站点

    动漫和游戏风格的动态壁纸大多在这些站上。它们不逐条标注授权，请自行确认后再使用。

    DesktopHut ↗ MoeWalls ↗ MotionBGS ↗ LiveBgs ↗ LiveWallp ↗ LiveWallpapers4Free ↗ MyLiveWallpapers ↗ WallsFlow ↗ WallpaperWaves ↗
    这些链接不代表背书。 Swaylume 与上述站点没有任何关联，不参与其运营，也无法保证其内容的授权状况、 画质或安全性。下载前请自行确认授权 —— 二次创作（动漫、游戏角色等）的 版权归原作者，自己在本机用是一回事，公开分发是另一回事。 发现哪个站点有问题，开个 issue 告诉我们，会撤掉。
    能下载来自己用 ≠ 能打包投稿。 很多免费素材站的授权允许你下载使用，却禁止再分发 —— Pexels 就明写禁止 「在其它素材站或壁纸站再分发」，而壁纸目录正是壁纸站。 换个封装格式不算「施加了创作性劳动」，所以这类素材不要投稿到精选目录。
    04透明边界

    你的桌面不该成为谁的云端素材库。

    动态壁纸能访问大量本地文件，所以 Swaylume 的默认策略是少拿权限、少留数据、少说大话。 能做的明确做到；做不到的明确告诉你。

    本地优先。

    壁纸、书签、导入记录和诊断报告都在你的 Mac。不会自动上传，也没有广告追踪脚本。

    公开 API。

    桌面层级、多 Space、省电策略和文件权限均使用 macOS 公开能力，为商店审核留出正路。

    诊断可带走。

    遇到黑屏或兼容问题，可导出已脱敏的本地报告；它包含状态和错误，不包含壁纸文件。

    不假装兼容。

    Windows 应用类壁纸和原生 Scene 渲染不承诺支持；Scene 有正规的视频预渲染方案。

    联系方式：有问题、要举报工坊内容，或涉及版权与下架事宜，写信到 futureback399@gmail.com。工坊内容托管在投稿者自己那边，我们只维护索引，但收到举报会处理。

    关于本站：这个网页使用 Cloudflare Web Analytics 统计访问量。它不写 Cookie，不做跨站追踪，也不给单个访客建立档案——我们只想知道有多少人来过、从哪来。上面那几条说的是 app 的行为，这一条说的是网页本身。

    05常见问题

    在下载之前，你大概想先问清楚这几件事。

    会不会很耗电？
    默认看不见时一帧都不画。屏幕被窗口盖满、锁屏、显示器休眠、系统睡眠、低电量模式，各自对应一个暂停原因，醒来自动恢复；用电池时可选择暂停或降帧率。可选的「锁屏无延迟（预热）」仍会暂停动画与媒体，只保留视频管线和网页进程以加快解锁，代价是少量额外内存；系统真正睡眠时不预热。开启前 app 会明确提醒。所有判断集中在一个调速器里，「壁纸为什么停了」永远只有一个答案，而且写在日志里。
    能用我自己的视频或图片吗？
    能，拖进窗口就行。视频支持 mp4 / mov / m4v（H.264 或 HEVC），图片支持常见格式和 GIF，网页壁纸支持 HTML / WebGL。webm / VP9 不能直接播，需要先转码 —— AVFoundation 不解这两种编码，这是系统的限制。
    和 Wallpaper Engine 比怎么样？
    诚实地说，各有各的强项。它有我们没有的：几百万张创意工坊内容、原生 Scene 渲染、成熟的编辑器。我们有它没有的：每个桌面（Space）用不同壁纸（Windows 上做不到）、按日出日落自动切换、以及明显更认真的省电策略。另外它没有 macOS 版，你现有的收藏可以用转换工具带过来。
    第一次打开被系统拦住，是软件坏了吗？
    不是。这个版本还没有经过 Apple 公证 —— 公证需要付费的开发者账号。macOS 会提示「无法验证开发者」，在「系统设置 → 隐私与安全性 → 安全性」里点一次「仍要打开」即可，全程点鼠标不用开终端，只需做一次。详细步骤在下载区。
    会上传我的数据吗？
    不会。壁纸、书签、导入记录和诊断报告都留在你的 Mac 上，没有自动上传，也没有任何广告追踪脚本。唯一的联网行为是你主动刷新壁纸目录时去拉一份索引；不刷新就完全不联网。诊断报告需要你自己点导出，内容是状态和错误，不含壁纸文件。
    支持哪些 Mac？
    macOS 14 或更高，Apple 芯片和 Intel 都能跑（通用二进制）。多显示器和 AirPlay 副屏都已实测。
